# QueueB — Final End-to-End Integration & Quality Assurance

Tanggal eksekusi: **29 Oktober 2026**. Host: Windows; timezone host Asia/Jayapura, timezone pelayanan tetap **Asia/Jakarta**. Laporan ini mencatat eksekusi lokal, bukan deployment atau pengesahan production.

## A. Executive summary

Baseline `01c9327914ed8b021bb1597af1e4e2d134c48f84` pada `main` cocok dengan `origin/main` saat preflight. [CI baseline sukses](https://github.com/yusranAbd/capstone-b-antrian/actions/runs/40790843797).

- Backend: **679 unit + 7 tooling data**, serta **386 integration tests / 31 suite** lulus. Regresi terarah suite profil sesudah barrier diperbaiki: **21/21** lulus, termasuk race password nyata.
- Runner browser: **13 kelompok PASS** — 12 Browser E2E dan satu Backend Integration untuk pembuatan appointment. Dua jalur HIBRIDA mencapai SELESAI. Chrome menjalankan UI Flutter release terhadap REST, Prisma/PostgreSQL dan Socket.IO nyata.
- Layout browser: **14 kombinasi portal/resolusi**, tanpa document overflow horizontal. Screenshot merupakan bukti render; pemeriksaan interaktif dan assertion memberikan bukti alur. Ini tidak membuktikan seluruh clipping, keyboard, atau text scaling pada perangkat fisik.
- Kamera Chrome memakai **video QR sintetis**, melalui decoder aplikasi sebenarnya. Web Speech memakai **engine terkontrol** untuk dispatch/deduplikasi CALL/RECALL; FlutterTts native diuji terpisah untuk aktivasi/mute/unmute: dua request, dua start, dua end, error 0. Voice `id-ID` baru muncul sesudah `voiceschanged`; probe awal kosong tidak berarti voice tidak tersedia. Tidak ada klaim kamera/speaker/monitor fisik lulus.
- **1.041 tes Flutter / 67 file PASS**, analyze bersih, Web release dan APK debug berhasil. **1 Android integration test / 4 kelompok PASS** pada Android 13 API 33 x86_64: lima navigasi pasien, secure-store restore, isolasi dua pasien, dan login/logout API empat role.

Perbaikan hanya menyentuh tes, runner dan dokumentasi QA. Tidak ada perubahan source bisnis frontend/backend, Queue Engine, RBAC, autentikasi, Prisma schema, migration, atau `.env`.
